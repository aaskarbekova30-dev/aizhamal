# Привет! Я Айжамал — Flutter-разработчик.

Увлеченный мобильный разработчик с опытом создания финтех-продуктов и кроссплатформенных приложений с нуля. Мой фокус — чистая архитектура (Clean Architecture), построение реактивного UI и интеграция облачных серверных решений.

## Технологический стек & Инструменты
- **Languages:** Dart, Clean Code, OOP, SOLID
- **State Management:** BLoC, Cubit, Provider
- **Architecture:** Clean Architecture (Data, Domain, Presentation), Dependency Injection (DI)
- **Backend & DB:** Supabase Server, PostgreSQL, REST API, Supabase Realtime, Row Level Security (RLS)
- **Security & UX:** Biometrics (FaceID/Fingerprint), Кэширование данных (Secure Storage), Intl (i18n / Локализация)
- **Tools & DevOps:** Git / GitHub, Git Flow, Postman
